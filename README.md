## Danger Shading

**What does it Do?**
The project is a minecraft shader that makes dangerous actions look more harmful! It's for people who want to challenge theselves
when playing minecraft. Currently, It changes the colour of the hand to red when taking damage, slowly turns your screen black when 
loosing air, shakes the camera when jumping or falling and changes the screen to become more grainy when in dark places.

**How to Assemble**
If you wish to re-compose the .zip file with your changes, you can do so via running:

> gradlew assemble

To access the created .zip file, head over to (.\build\releases). In that folder, you should be able to see your newly
created shader pack.

**How to Use**
To use this shaderpack, you must have a version of Minecraft Java that is/above 1.21.5.

You must also have Iris Shaders installed so the shader can run.

Once you have those things ready, follow these steps:

1. Launch Minecraft via the Iris profile/installation.
2. In Minecraft, create a single player world.
3. Once loaded in, press `esc` to enter the game menu. After that, press *Options*, then *Video Settings* and finally *Shader Packs*.
4. Click *Open Shader Pack Folder*, which should open up the file explorer. Select the shader's .zip file as the selected file, before
   pressing open.
5. Go back to the *Shader Packs* section, and select the shader.
6. Once reloaded, exit the menu and enjoy the shader!
